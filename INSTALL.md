# Installation

## Status

`rag_builder` is currently in active development. A stable installation procedure has not yet been established.

## Initial Platform

Initial development targets Windows.

## Requirements

Planned baseline requirements include:

- A conforming ISO C compiler
- A supported Windows development environment
- Git
- Access to the configured local STN-LABZ knowledge source directory

## Build

Build instructions will be added when the initial source tree and build system are established.

## Runtime

The application will use configuration to locate source material and output destinations. Local paths will not be permanently hard-coded into the core application.
